# AI 表情包工厂

> 一句话生成你的专属表情包

2026 Qoder 高校创造力大赛 · LifeHack 赛道参赛作品

## 项目简介

AI 表情包工厂是一个基于 Web 的表情包创作工具。用户只需输入一段文字描述（心情、场景、吐槽），AI 智能算法会自动匹配最合适的表情包模板，并提供在线编辑和下载功能。

## 核心功能

- **AI 智能匹配**：自然语言理解，精准匹配表情包模板
- **40+ 精选模板**：覆盖开心、难过、生气、搞笑四大类别
- **自由编辑**：自定义上下方文字、字体大小、颜色、描边
- **一键下载**：高清 PNG 格式，即下即用
- **随机灵感**：不知道写什么？一键获取创作灵感
- **响应式设计**：手机电脑都能用

## 技术栈

- 纯前端实现（HTML + CSS + JavaScript）
- Canvas API 实现图片合成
- 智能关键词匹配算法
- 现代 CSS 动画与渐变设计

## 使用方法

1. 在输入框描述你的场景或心情
2. 点击「AI 匹配模板」或浏览模板库
3. 选择喜欢的模板
4. 自定义文字内容和样式
5. 点击下载保存表情包

## 开发说明

本项目使用 Qoder 开发，部署在 Qoder Sites。

```bash
# 本地预览（需要任意静态文件服务器）
npx serve .

# 或使用 Python
python -m http.server 8000
```
